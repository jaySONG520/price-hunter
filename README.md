# Price Hunter

本地运行的电子数码套利决策工具。它用一手平台到手价和闲鱼卖出侧样本做对比，帮助判断一个商品是否值得买入倒卖。

当前版本不做绕风控、验证码破解、多账号、代理池、自动抢券、自动下单。程序负责发现机会、计算收益、提醒和打开页面，登录、领券、付款、发布由你人工确认。

## 功能

- 商品库：锁定电子数码板块，记录目标商品、买入价、平台链接、关键词。
- 闲鱼采样：粘贴闲鱼搜索结果文本，自动解析标题、价格、成色标签。
- 套利计算：计算闲鱼中位价、预估成交价、0.6% 闲鱼平台成本/风险金、运费包装、净利润、利润率。
- 决策建议：按样本数、最低利润、最低利润率输出“可以买 / 观察 / 不买 / 样本不足”。
- 半自动辅助：生成并打开闲鱼、京东、淘宝、天猫、抖音搜索链接。
- 官方 API 预留：配置文件已预留各平台 app key/app secret。

## 运行

```powershell
python -m price_hunter.server
```

打开：

```text
http://127.0.0.1:8765
```

也可以双击或运行：

```powershell
.\run.ps1
```

## 闲鱼成本规则

按你的要求，闲鱼卖出侧固定计入：

```text
闲鱼平台成本/风险金 = 预计成交价 * 0.6%
```

不设置封顶金额。其它成本包括运费、包装、压价折扣，可在每个商品上单独设置。

## 官方 API Key 获取方向

### 京东

- 京东联盟：适合商品推广、券、佣金、返利场景。
- 京东开放平台 / 宙斯：适合更完整的开放接口能力。
- 流程：注册/登录、入驻、创建应用、提交审核、在应用详情中获取 app key/app secret、申请接口权限。

### 淘宝 / 天猫

- 淘宝开放平台：创建应用后在 APP 证书页面获取 App Key 和 App Secret。
- 淘宝联盟/阿里妈妈：适合淘宝客、优惠券、推广位 PID、佣金能力。
- 流程：实名认证账号、创建应用、申请权限、获取 app key/app secret、配置推广位。

### 抖音 / 抖店

- 抖店开放平台：创建自用型或工具型应用。
- 流程：开发者入驻、创建应用、获取 app key/app secret、店铺授权、申请接口权限。

## 边界

会做：

- 低频、透明、可人工确认的监控。
- 官方 API 优先。
- 本地保存数据，不保存账号密码。
- 到点提醒和打开页面。

不会做：

- 绕过平台风控。
- 破解验证码/滑块。
- 隐藏自动化痕迹。
- 代理池、多账号抢券。
- 自动提交领券、下单或支付。
